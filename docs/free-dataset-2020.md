# 2020年度の無料CSVと要望アンケート

## 実装範囲

2020年度（令和2年度）・全国の公共下水道。原資料第10表の事業会計を母集団とし、団体コード・事業キー・会計区分・年度で1行とした。2024年度の商品とは別の商品版・収録範囲。現行の家庭用料金として使わない。

- 1,189事業会計、174列、主CSVは2,610,114 bytes（約2.5 MiB）。法適用906、法非適用283。
- 基本9項目、3料金指標、費用21項目の年額・単位費用・構成比・県内中央値・差・比較件数・状態、識別子と自動検証情報。
- 県内費用比較に使えるのは法適用で年間有収水量が正の900事業会計。母数は各費目の有効値で決定し、法非適用・欠損・水量0を中央値の0として扱わない。
- 共同運営団体も公式の団体コードで1回だけ収録。現在の構成市町村関係を2020年度に適用せず、金額を構成市町村へ配賦しない。県は団体コードの先頭2桁。
- 目的別の業務費・総係費の合計と個別列は二重に足さない。目的別と性質別も別分類であり合算不可。分母の営業費用・性質別費用合計も収録。
- 2020年度単年のためR2→R6推移は含めない。家庭用月額は第33表13列の公式値で、使用料単価からの換算はしない。

既存の無料画面・URL・無料CSV・2024年度商品とnote設定は維持。DB・公式Excel・既存金融JSON・GISは変更しない。通常ビルドにDB・原資料キャッシュ・ネット接続は不要。

## 生成と再検証

```sh
FREE_DATA_SOURCE_ROOT=/path/to/e-stat pnpm datasets:free2020
pnpm datasets:free2020:check
FREE_DATA_SOURCE_ROOT=/path/to/e-stat python3 scripts/datasets/verifyFree2020.py
pnpm lint
pnpm test
pnpm build:pages
```

`FREE_DATA_SOURCE_ROOT`は既存キャッシュのルートを実行時だけ指定する。個人のパスを設定ファイルに保存しない。原資料9ファイルのURL・SHA-256・決算年度・カタログ年を`config/free-2020-sources.json`で固定し、SHA不一致・年度違い・重複・結合漏れでは生成を止める。

第20/21表の費目定義、円/m³換算、基本指標の計算、中央値は既存コードを共用。基本項目の座標は既存横持ちETLとフィールドマッピングに対応するR2の座標。原資料の数値は全件自動照合し、当時の公式レイアウトで採用項目の表・行・列と項目名を別途照合した（下記参照）。事業ごとの全数値の手動照合ではなく、包括的な「手動確認済み」とは表示しない。

通常ビルドは生成済み8ファイルとコード・原資料メタデータのハッシュを検証する。生成コードを変えた場合は、原資料からの再生成を要求する。公開対象は2020年度の無料ファイルだけ。2024年度の完全版は引き続きGit管理外。

## 画面とGoogleフォーム

- `/datasets/`：2020年度無料CSVのボタンは、公開確認後にGoogleフォームの入力画面へ直接遷移する。未確認時は準備状況のページへ遷移。
- `/datasets/free-2020/`：アンケート案内を先に表示し、収録内容をその下に置く。
- `/datasets/free-2020/download/`：主CSV、原値CSV、原表の行位置CSV、計算式CSV、列定義、出典、README、版情報。公式Excelの取得リンク9件。noindex、サイトマップ対象外。
- フォーム未公開時は回答用リンクを出さず準備中とする。専用ダウンロードページにはファイル確認用として取得ボタンを残す。
- Googleフォームの完了メッセージに専用ページのURLを置く。ローカルストレージやURLパラメータから回答完了と推測しない。
- 静的ファイルなのでURLの再共有や直接取得は防止しない。認証・独自API・独自決済は追加しない。

フォームの設問は、必須の「今後ほしいデータ」複数選択と、任意の利用目的・希望年度地域・要望。氏名・メール収集なし、1回制限オフ、回答概要公開オフ。フォームの編集権限と回答スプレッドシートは所有者1名・一般アクセス制限付き。回答・集計・管理画面URL・アカウント情報はGitや公開サイトに入れない。

Googleフォームと回答シートは所有者アカウントで下書きを作成済み。公開URLは画面の埋め込みHTMLから確認した正規の回答URLで、設定ファイルに記録してもdraftの間はリンク非表示。フォームは未公開、回答0件。公開と外部テスト送信は承認待ち。


## 原資料と計算の追跡（2026-09-26追加）

- `input-values.csv`：1,189行・35列。計算前の公式セル値を事業会計単位で抽出する。項目IDは列名末尾の角括弧内。欠損記号は元のまま残し、数式として解釈されうる文字列はアポストロフィで無効化する。原資料9ファイルそのものの再配布ではない。
- `source-records.csv`：11,324行。公式原表のシート名・Excel行番号と、調査様式の表番号・行番号を区別する。`sources.csv`の列番号はExcelの列文字ではなく`列013`などの見出しに対応する。
- `calculations.csv`：主CSV174列の計算式、入力項目ID、直接入力の原表位置、欠損・丸め・比較条件。派生項目の入力IDを同じ表でたどれば原値へ到達できる。
- ダウンロード画面の公式Excelリンクは、生成に使用した出典メタデータから生成。団体別の年鑑個表PDFとは異なる「地方公営企業決算状況調査の原表」と明示。原本はe-Statから取得する。提供元の更新でハッシュが変わる可能性がある。2026-09-26に9件を再取得し、生成に使った原本のSHA-256との一致を確認した。
- 画面、主CSV、原値、計算式、出典は同じmanifestの版とハッシュにまとめる。2024年度の値は混ぜない。

## 運営者の集計方法

Googleフォームの「回答→概要」で選択肢ごとのグラフを見る。「スプレッドシートで表示」から任意回答も確認する。フォームの編集者ビューと回答シートをリンク共有しない。フォームの「結果の概要を表示する」はオフを維持する。

テストを送る場合は、任意の要望欄に「動作確認テスト・集計対象外」と記入し、商品企画の集計時はその行を除外する。未計測・未公開・0回答を需要なしと判断しない。回答の保存先はGoogleであり、サイト側には同期しない。
